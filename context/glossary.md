# Glossary
- **Execution record** — evidence for one agent run: request id, execution id, agent, tools invoked, status, duration, error class.
- **Tool policy** — the frozen map of agent → permitted tools, built from agent registrations at startup.
- **Gateway** — the runner-bound object an agent uses to call tools; it accepts only a tool name and arguments.
- **Radius** — RepoIntent architectural maturity score (1–5). Earned by assessment, never self-declared.
